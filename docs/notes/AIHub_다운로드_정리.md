## 2. 지켜야 할 규칙 (설계서 3.1.3, AI Hub 문의 답변 2026-10)
- 쓰는 사람이 **본인 계정으로 직접 신청**한다. 팀원끼리 파일을 넘기지 않고 코드만 공유한다.
- 원본과 재가공본 모두 해외 서버 · 클라우드 · 외부 API(Sonnet, Gemini 임베딩 등)로 보내지 않는다. S3도 쓰지 않는다.
- 레포에 커밋하지 않는다. 처리는 학과 서버에서만 한다.
- 레지스트리와 데이터 필드에 `contains_aihub`를 표시한다.
- 출처 문구: "본 프로젝트는 한국지능정보사회진흥원의 사업결과인 AI Hub 「기계독해」 데이터를 활용하였다."

## 3. 받는 흐름 (합의안)
학과 서버는 외부 인터넷이 안 될 가능성이 높아서(아직 확인 안 됨), 개인 PC를 한 번 거쳐 옮긴다.
설계서는 "학과 서버에만 둔다"고 되어 있어 이 부분이 조금 다르다. 본인 계정으로 받은 데이터를 국내 개인 PC에 잠깐 두는 건 이용 조건에 어긋나지 않는다고 판단했고, 처리는 하지 않고 옮기기만 하는 단계로 쓴다.

1. 데이터 페이지 "소개" 탭에서 브라우저로 두 파일을 내려받는다.
   - API · aihubshell로 받으려면 Windows에서는 WSL이 필요하다.
   - 분할 파일(part)로 받았다면 합친다: `find . -name "*.part*" | sort -V | xargs cat > 파일명.zip`
2. **레포 밖** 폴더에 저장한다(예: `C:\aihub_tmp`). OneDrive · Google Drive 등 클라우드 동기화 폴더는 피한다.
3. `scp`로 학과 서버 본인 계정 폴더로 옮긴다.
   예: `scp C:\aihub_tmp\*.zip <계정>@<학과서버>:~/aihub/`
4. 서버에서 파일이 잘 왔는지 확인한 뒤 **PC 사본을 지운다**(휴지통도 비우기).
5. 팀에 "PC는 옮기는 단계로만 썼고 사본은 지웠다"고 알린다.

**변경 (2026-11-22, 엄윤종):** 전처리(`scripts/data/aihub_sample.py`)는 데이터를 본인 계정으로 직접 받은 **본인 PC에서 돌리고**, 결과(`data/interim/aihub/`, git 제외)를 학과 서버로 올린다. 본인이 받은 데이터라 이용 조건에 어긋나지 않는다고 판단했다. 설계서 3.1.3("학과 서버에서만 처리")과 CLAUDE.md 규칙과 다르므로 팀에 공유한다.
- 그대로 지키는 것: 외부 API · 임베딩 · 클라우드 동기화 폴더 · S3 금지, 팀원끼리 파일 공유 금지, 커밋 금지, 학습은 학과 서버.
- 올린 뒤 PC의 원본 zip · 압축 푼 파일 · 전처리 결과를 모두 지운다(휴지통도 비우기).

**예외 (2026-11-26, 엄윤종): 학과 서버 팀 공용 계정(`t26112`)에 AI Hub 데이터를 둔다.**
- 사유: 학과 서버 사용 가이드(2026 P-프로젝트)는 팀 계정만 안내하고, 개인 계정을 따로 만들어도 되는지(허용되는지) 몰라서 팀 계정 공간에 두었다(11-26 기준). 개인 계정이 허용되면 그쪽으로 옮긴다(서버 관리 학생에게 문의 필요). 설계서 3.3.5("신청자 계정 소유, 타 계정 차단")와 2절("팀원끼리 파일을 넘기지 않는다")과 다르다.
  같은 계정이라 `chmod 700`으로도 팀원 접근을 막을 수 없다.
- 줄이는 방법:
  - AI Hub 파일은 `/home/t26112/easyq-data/upload/<폴더>/`에만 둔다(설계서 v1.1 7.4.2 · 7.4.30: "AI Hub가 섞인 데이터는 반드시 upload/<폴더>/에만"). 입력 `upload/ds-draft-5-inputs/`, 결과 `upload/ds-draft-5/`. 다른 곳으로 복사하지 않는다.
  - 설계서 v1.1은 `/home/t26112/easyq-data/`를 "신청자 계정 소유, 다른 계정 접근 차단" 폴더로 정했지만, 실제로는 팀 공용 계정이라 이 예외가 필요하다.
  - 신청자(엄윤종)만 이 파일을 다룬다. 팀원은 열거나 복사 · 내려받기 하지 않는다(팀에 공지).
  - 서버의 VS Code(Copilot 등 AI 확장이 켜진 계정)에서 AI Hub 파일을 열지 않는다. 터미널 명령으로만 다룬다.
  - 학습 · 등록이 끝나면 `upload/ds-draft-5-inputs/`의 AI Hub 입력 파일은 지운다.
