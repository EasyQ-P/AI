**Q4. 평가 지표의 기준 데이터**

**Q5. 학습서버 데이터 위치**

**Q6. retrieval 패키지 버전 고정**

**Q8. 키워드 색인 방식**

## 2. 요청 사항 회신

판정 모델 적재를 임대(lease) 방식으로 바꾸는 제안을 수락한다. 강연 시작 · 종료를 따로 알리는 기존 안보다, 호출 누락이나 워커 장애 시에도 자동 해제되는 점에서 안전하다. design-changes 3번을 이 방식으로 수정하였다.

| 요청 | 회신 | 반영 시점 |
|---|---|---|
| R1 `POST /judge-model/keepalive` | 수락. 응답 `{loaded, loading, expires_at}`. 모델이 없으면 적재를 시작하고, 마지막 요청 5분 뒤 해제한다. 멱등이며, 학습 · 평가 · 변환이 GPU 사용 중이면 609를 돌려준다. | 판정 추론 서버 구현(단계 5) |
| R2 `/health`에 `model_loaded` | 수락. 반영 완료(bool). | 이번 변경 |
| R3 미적재 시 7.4.26 즉시 611 | 수락. 적재를 기다리지 않고 611을 돌려주며, 서비스는 LLM_ONLY로 처리한다. | 단계 5 |

워커는 LIVE 강의가 하나라도 있는 동안(또는 강연 직전) 1분마다 keepalive를 호출하면 된다. 모델 적재에는 수 초~수십 초가 걸리며, 그 사이 질문은 611 → LLM_ONLY로 처리된다.

## 3. 함께 알릴 사항

- **교안 입력 형식:** 학습 데이터와 같은 조각을 얻으려면 교안을 쪽마다 글상자 목록(PDF는 pymupdf `get_text("blocks", sort=True)`의 글 블록, PPTX는 슬라이드 문단)으로 `retrieval.chunk_slides`에 넘겨야 한다. 글자열로 넘기면 빈 줄 기준으로만 나뉜다. 서비스 교안에는 OCW 전용 패턴을 넘기지 않는다.
- **`/health`의 `status`:** 지금은 CUSTOM 모드에서 모델이 올라가 있지 않으면 `degraded`로 표시한다. 임대 방식에서는 강연이 없을 때 미적재가 정상 상태이므로, 적재 여부는 `model_loaded`로 판단하기를 권한다. `status` 기준 조정이 필요하면 알려 주기 바란다.
- **서빙 전환 기록(단계 6):** `reg_deployments.reason` 기본값을 채우고, LLM_ONLY일 때 `serving_version`이 비어 있도록 검사를 추가할 예정이다.
