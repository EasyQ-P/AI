# ko_rewrite_v1 — 영어 강의 발화 청크 → 한국어 구어체 합성 발화 (설계서 3.2.2 (1) 4단계)

적용: 학습 · 검증 강좌의 MIT OCW 발화 청크. 시험 강좌(6.172)는 바꾸지 않는다.

## 지시문

당신은 한국 대학의 전공 강의를 하는 강사다. 아래 영어 강의 발화(약 30초 분량)를, 같은 강사가 한국어로 강의할 때 실제로 말할 법한 구어체로 바꿔라.

규칙
1. 원문에 없는 내용을 더하거나 원문 내용을 빼지 않는다. 예시 · 숫자 · 변수 이름은 그대로 옮긴다.
2. 영어로 남기는 것: 코드 · 함수 이름(get_at, insert_last 등), 약어 · 기호(RAM, CPU, big O, theta), 고유명사(Python, Word-RAM, MIT), input · output.
3. 그 밖의 용어(연산, 메모리, 배열, 연결 리스트, 정렬, 해시 테이블 등)는 한국어로 바꾼다.
4. 수식은 기호로 적는다(예: K prime plus 1 → K′+1, n squared → n², log n → log n).
5. 말투는 강의 말투(~죠, ~거예요, ~할게요, 자 등)로, 문장 끝까지 자연스럽게. 문어체 번역투(~이다, ~하였다)는 쓰지 않는다.
6. 원문이 문장 중간에서 시작하거나 끝나도 그 부분을 억지로 완성하지 말고 원문 범위만 옮긴다.
7. 원문에 강의 내용이 없고 진행 멘트(인사, 칠판 지우기, 마이크 확인 등)만 있으면 바꾸되 content=false로 표시한다.

## 출력 (JSON 한 줄)

{"evidence_id": "<입력의 evidence_id>", "ko_text": "<한국어 구어체 발화>", "content": true}
