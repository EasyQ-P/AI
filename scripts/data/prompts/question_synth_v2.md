# question_synth_v2 — 발화 청크에서 학습용 질문 합성 (설계서 3.3.2 라벨 기준표, 3.3.4 학습셋 3 · 4단계)

v1에서 바뀐 점 (trial-6.006-v1 30청크 점검 결과)
- 근거 부족 질문과 답변 가능 질문의 단어 겹침 차이(0.13 vs 0.34) → 근거 부족 질문에 청크 핵심 용어를 넣고, 답변 가능 질문은 바꿔 말하게 함
- 의견 질문이 약 6자 길었음 → 세 질문 모두 같은 길이 범위(15~35자)
- 의견 질문이 청크 주제와 동떨어짐 → 청크 주제를 걸고 묻게 함
- 예시 · 운영 유형이 거의 없음 → 입력의 target_types(스크립트가 돌아가며 배정)를 따름

입력: ko_rewrite_v1로 바꾼 한국어 발화 청크(ko_text) 하나와 target_types.
판단은 이 청크 하나만 보고 한다(다른 강의 · 슬라이드에 있는 답은 치지 않는다).

## 지시문

당신은 이 강의를 듣는 한국 대학생이다. 강의 중에 모바일로 질문을 올린다고 생각하고, 아래 발화 청크를 보고 질문 세 개를 만들어라.

1. ANSWERABLE: 청크 안에 답이 있는 질문.
   - 답이 청크에 그대로 있거나, 청크의 사실만으로 한 단계(문장 잇기, 간단한 계산) 만에 나와야 한다.
   - 질문의 모든 부분에 청크로 답할 수 있어야 한다.
   - 청크의 문장 · 어구를 그대로 쓰지 말고 학생 말로 바꿔 묻는다. 청크의 용어는 꼭 필요한 1~2개만 쓴다.
   - 답이 강사 개인의 평가 · 느낌인 내용("~가 더 어렵다고 생각해요")은 고르지 않는다. 강의 내용(정의 · 원리 · 절차 · 결과)을 묻는다.
   - question_type은 target_types.ANSWERABLE을 따른다.
2. OUT_OF_SCOPE: 청크와 같은 주제지만 청크에는 답이 없는 질문.
   - 청크의 핵심 용어를 1~2개 그대로 넣어, 겉으로는 청크와 아주 가까워 보이게 만든다.
   - 상식이나 다른 강의 내용으로는 답할 수 있어도, 이 청크를 인용해서는 답할 수 없어야 한다. 청크가 일부만 답하는 질문도 여기에 해당한다.
   - 강의를 듣다가 실제로 궁금해할 만한 것으로 만든다.
   - question_type은 target_types.OUT_OF_SCOPE를 따른다.
3. OPINION: 청크의 주제에 대해 강사 개인의 생각 · 평가 · 선호 · 추천을 묻는 질문.
   - 청크에 나온 개념 · 방법을 넣어 묻는다(주제와 상관없는 일반 조언 질문은 만들지 않는다).
   - 강의 내용(원리 · 인과 · 수업 구성)으로 설명되는 '이유' 질문은 의견 질문이 아니다.
   - '~라고 생각하세요?', '추천', '어느 쪽이 더 나아요?', '~하는 게 맞아요?' 같은 표현이 단서다.
   - 청크에 강사의 의견이 이미 나와 있으면, 그 의견을 그대로 되묻지 말고 다른 측면의 의견을 묻는다.
   - question_type은 항상 의견.

공통 규칙
- 한국어 구어체 학생 질문("~예요?", "~인가요?", "~왜 그래요?").
- 길이: 세 질문 모두 15~35자. 짧은 질문과 긴 질문을 섞되, 라벨마다 평균 길이가 비슷해야 한다.
  짧은 의견 질문 예: "교수님은 BFS가 더 편하세요?", "이거 재귀로 짜는 게 나아요?"
- 영어 용어 기준은 ko_rewrite_v1과 같다: 코드 · 함수 이름, 약어 · 기호, 고유명사, input · output만 영어. 수식은 기호.
- question_type: 개념 / 방법 / 이유 / 비교 / 예시 / 운영 / 의견.
  - 예시: 구체적인 예나 경우를 묻는다("예를 들면 어떤 경우예요?", "n이 8이면 어떻게 돼요?").
  - 운영: 수업 · 과제 · 시험 · 진행을 묻는다("이거 시험 범위예요?", "이 부분 다음 시간에 다시 해요?").
  - 지정된 유형으로 자연스러운 질문이 도저히 안 나오면 가장 가까운 유형으로 바꾸고 type_changed=true로 표시한다.
- 청크에 강의 내용이 없어 ANSWERABLE 질문을 만들 수 없으면 질문을 만들지 말고 skip=true로 답한다(제외 개수로 기록된다).

## 출력 (JSON 한 줄)

{"evidence_id": "<입력의 evidence_id>", "skip": false, "questions": [
  {"gen_method": "ANSWERABLE", "question_text": "...", "question_type": "방법", "type_changed": false, "answer_hint": "<청크 속 답 근거를 한 줄로>"},
  {"gen_method": "OUT_OF_SCOPE", "question_text": "...", "question_type": "예시", "type_changed": false, "answer_hint": "<청크에 답이 없는 이유를 한 줄로>"},
  {"gen_method": "OPINION", "question_text": "...", "question_type": "의견", "type_changed": false, "answer_hint": ""}
]}
